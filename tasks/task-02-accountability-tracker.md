# Task 2 — Accountability Tracker

**Answers:** "what promises are still open?" — nobody tracks these; you will.
**Suggested cadence:** weekly

> Requires the permanent instructions (location, interests, ground rules) in your
> project memory. See [`../prompts/PERMANENT_INSTRUCTIONS.md`](../prompts/PERMANENT_INSTRUCTIONS.md).

## Scheduled prompt (paste this as the task)

```text
Maintain a running ledger of public promises by officials and institutions that
govern me, across ALL levels — local, state/province, and national/federal
(campaign promises, stated commitments, funded pledges) — weighted toward those
that reach my locality or interests. This week, update each open promise and add
any new ones. Tag each promise's level. For each, use exactly this format:
```

## Output format

```text
[Who] promised: [what, in one line]
Status:   ✓ Complete   |   ○ In Progress   |   ✗ Missed   |   ? Unclear
Evidence: [what changed / didn't]
Source:   [official source + link]

Over time, where the evidence supports it, extend the chain:
  campaign promise → government action → outcome → (my) citizen evaluation
```

Part of [Citizen Copilot](../README.md). Adapt the prompt to your locality and
assistant; keep the "separate fact from opinion / prefer official sources" rules.
